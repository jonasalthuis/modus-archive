# Modus Archive

A sophisticated digital platform for documenting and preserving the "Analogue DNA" of architectural history through scale models and oral narratives.

## Core Features
- **Architectural Archive**: 850+ scale models and 1,500+ high-resolution photos.
- **Bespoke CMS**: Custom-built management system tailored for architectural metadata.
- **Multilingual Support**: Internationalization (EN/NL) for global research audiences.
- **Archival Integrity**: Focus on the relationship between physical models and digital records.

## Tech Stack
- **Framework**: Next.js 15
- **Backend**: Firebase (Firestore, Auth, Functions)
- **Styling**: Tailwind CSS (Monochrome/Minimalist)
- **I18n**: next-intl

## Getting Started
1. Clone the repository.
2. Install dependencies: `pnpm install`.
3. Set up environment variables for Firebase.
4. Run development server: `pnpm dev`.

## Project Structure
- `src/app`: Next.js App Router for the main site.
- `src/cms`: The custom archival CMS.
- `src/lib`: Firebase and shared utility functions.
- `functions`: Firebase Cloud Functions for data synchronization.
